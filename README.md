# Temperature Converter

Two Python functions for converting temperatures between
Celsius and Fahrenheit in both directions.

## What It Does
- celsius_to_fahrenheit(c) — converts Celsius to Fahrenheit using (c × 9/5) + 32
- fahrenheit_to_celsius(f) — converts Fahrenheit to Celsius using (f - 32) × 5/9
- Accepts both integers and floats
- Raises a TypeError if input is not a number

## Sample Output
celsius_to_fahrenheit(21)   # 69.8
fahrenheit_to_celsius(21)   # -6.111...

## Requirements
- Python 3.x
